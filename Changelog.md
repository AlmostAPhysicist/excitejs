# Changelog

All notable changes to this project will be documented in this file.

## [0.2.0] - 2026-7-17

### Added

* Preactions
* Scheduler
* Extensive list of Examples

### Planned

### Added

* Priority control for reactors
* DOM clicker example
* TypeScript type declarations
* npm package publishing support
